Skąd pobierane są tytuły i długości?

Domyślnie (bez klucza API): używamy Piped API — publicznego frontendu YouTube z włączonym CORS, zwraca tytuł i długość w sekundach jednym zapytaniem. Fallback: YouTube oEmbed (tytuł) + CORS proxy (długość).

Opcjonalnie — klucz YouTube Data API v3 (najszybsze, oficjalne):

  1. Google Cloud Console → nowy projekt
  2. APIs & Services → Enable APIs → YouTube Data API v3
  3. Credentials → Create Credentials → API key
  4. W kluczu ustaw Application restrictions → None (lub dodaj swoją domenę), inaczej przeglądarka dostanie 403
  5. Wklej klucz w polu poniżej — zostanie zapamiętany w localStorage

Format wyjścia: ID,SEKUNDY,tytuł — kompatybilny z script.js.

Wklej linki, a potem kliknij przycisk pobierania danych.
